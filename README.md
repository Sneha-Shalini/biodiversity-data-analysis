# Biodiversity Data Analysis - EDA Project
Analyzed 15,000+ species records from IUCN Red List dataset.

**Tools:** Python, Pandas, Matplotlib, Seaborn
**Skills Shown:** Data Cleaning, EDA, Data Visualization

**Key Insights:**
1. Mammals have highest extinction risk (32%)
2. Habitat loss is #1 threat for 78% species
3. Tropical regions show highest biodiversity loss

Dataset: [IUCN Red List on Kaggle](https://www.kaggle.com/datasets/aravindram/iucn-red-list-threatened-species)
Notebook: See `analysis.ipynb`
